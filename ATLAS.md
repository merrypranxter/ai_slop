# SLOP ATLAS — visual instrument (this branch)

This branch is **not a rewrite of the knowledge graph**. `main` stays the canonical notebook. `visual-atlas` is the **lab instrument** layered on top of it: dark chrome, neon, searchable, copyable, and built to compile a problem instead of browsing a pile of files.

The live interactive atlas is the Grok app attached to this work. This file is the repo-side map of that instrument.

## How to use the instrument

1. **Search** (⌘K) across operators, minds, protocols, glossary, and canon.
2. **Open an operator** when you need a named move, not a vibe.
3. **Install a Temporary Mind** when the selection procedure itself should mutate — copy the full prompt.
4. **Read DAVID** as a hypothesis registry. Creative utility ≠ mechanism confidence.
5. **Draw a specimen** when you want a compiled brief: invariant, foreign mandate, escape block, medium stack. Reroll individual slots. Copy the brief into the generator.
6. **Bookmark** anything that earns another experiment.

## Five laws (always on)

1. Give the weirdness a cause.
2. Keep both sides alive.
3. Translate into operations.
4. Preserve ancestry.
5. Make failure informative.

## Why a second branch

`main` remains a research notebook you can clone and grep. This branch is the **interface**: same graph, visual, interactive, neon-chrome, not a seizure. If the instrument and the notebook ever conflict, the notebook wins.
