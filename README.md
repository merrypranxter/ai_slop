# AI Slop Hub

This repository is now organized as a **readable instruction hub** for AI-assisted slop generation workflows.

## Start Here
- `/ai_readable/general/README.md` → Core philosophy, strategy, and foundational discussions
- `/ai_readable/audio_suno/README.md` → Audio/Suno-specific prompting and experimental material
- `/ai_readable/art/README.md` → AI art transformation logic, frameworks, ideas, and weird-prompt persona palettes
- `/ai_readable/personality_prompts/README.md` → Installable cognitive-personality prompts ("temporary minds"): research, consolidation, and the 26-prompt library
- `/ai_readable/semantic_systems/README.md` → Semantic engines, controllers, latent-space games, and TOPOS-SRE
- `/ai_readable/video/README.md` → AI video track (structure prepared; add source docs when available)

## Source Preservation
All original source documents remain available:
- `/general`
- `/art`
- `/suno_slop/prompting`
- `/originals` → archived intake batches (see `/originals/README.md` for the file-by-file mapping)

No original information has been deleted. The `ai_readable` directory is a reorganized, AI-friendly layer built on top of the original corpus.

## Adding New Material
Drop new files into `/new_to_be_processed_by_copilot_agent`. They get transcribed into the right
`ai_readable` category, mapped in that category's README, and the originals are archived under
`/originals/<intake-batch>/`.
