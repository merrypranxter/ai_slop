## Canonicalization rule

A source is evidence, not a folder destiny. One source can feed ten docs; ten passages from one source can belong in ten different systems. Canonical docs should synthesize duplicated material and keep provenance links.

The complete historical wording remains in `ai_readable/`, `originals/`, and legacy folders. Those layers answer **what was said**; `docs/` answers **what the project currently means and how to use it**.
