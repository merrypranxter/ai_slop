# Temporary Minds Support Architecture

These pieces are **not extra personalities**. They regulate, test, or author the 26 minds.

## Regulators / modifiers

1. **Structural Satiation / Conceptual Allergy v2** — fingerprint successful ideas by ontological substrate + intervention direction + resolution topology; reject near-repeat skeletons.
2. **Cliché Mortality Tax** — prune trajectories converging on predictable analogy, standard symmetry, expected resolution, consensus association, or generic creative-AI territory.
3. **Afterlife Module / Memory Ecology** — after success in long sessions, mark territory exhausted, inspect suppressed alternatives, force the next idea into a different functional role.
4. **Operator Burnout** — optional hard mode: successful operators retire for the rest of the run.
5. **Strategic Ambiguity / Use Before Naming** — let an anomaly affect at least one later step before exhaustive explanation domesticates it.

## Validators

1. **Structural-Error Sieve** — coherent relational near-misses only; reject random corruption and token mush.
2. **No-Metaphor Leak / Literal Consequence Test** — if restoring ordinary meaning leaves the result unchanged, the mutation was decorative.
3. **Observer Scar / Developmental Footprint** — N must alter a state variable constraining N+1 when feedback is claimed.
4. **Structural Ancestry Requirement** — a hybrid Z must require both parents and be reducible to neither; sequential stacking is not offspring.
5. **Generative Leverage Ratio** — prefer the smallest governing mutation that produces the largest structured consequence field.
6. **Rick’s Veto / Hostile Cull Gate** — final test: identifiable operation, changed selection, structured divergence, causal load, no dependency on theatrical prose, not equivalent to “be weird.”

## Construction laws

### Sensorium Before Emotion
If an invented affect responds to X, define how X is detected.

### Operational Minimalism
Prompt length follows algorithmic necessity. Remove mythology, fake neuroscience, and terminology that performs no procedural work.

### Procedural Simulation, Not False Neural Claims
A pasted prompt can impose an explicit procedure. Do not say it literally changes weights, embeddings, hidden states, or latent geometry.

## Universal installation chassis

Documentation/reference cards can be rich. Executable installations should contain only:

- name and core rule;
- mandatory execution steps;
- selection rule;
- propagation/state only when needed;
- mechanism-specific escape-route blocks;
- one decisive falsification question when possible;
- normal task output rather than narrated mechanism unless diagnostic mode requested;
- duration/scope.

## Benchmark

Common tasks from the support audit:

- redesign a chair for a very small room;
- invent an organism for a difficult environment;
- invent a non-verse/chorus musical structure;
- intervene in a city traffic system where fixes worsen congestion;
- invent conceptual artwork about memory.

Compare against an ordinary baseline using the same task.

Score 0–3 on:

- mutation fidelity;
- selection shift;
- causal load-bearing;
- difference from baseline;
- task fidelity;
- structured novelty;
- economy/leverage;
- administrative overhead (reverse scored).

Stateful systems also score **Developmental Effect**.

## Hard fails

Examples:

- Primitive Deletion quietly substitutes a new primitive;
- Taxonomic Contagion imports mushrooms/germs/court imagery instead of foreign causal rules;
- Oneiric Contamination becomes dreamy prose;
- Axiom Fracture resolves through compromise;
- Error Axiomatization rewards incoherent wrongness;
- Destructive Compression leaks decorative foreign-domain vocabulary.

- Morphological Revulsion / Teleological Tenderness → Synthetic Valence presets;
