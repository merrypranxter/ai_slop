# Temporary Minds — Canonical Inventory

## What a Temporary Mind is

A Temporary Mind is an **explicit procedural mutation of search/selection/reasoning for one task or session**. It does not claim to rewrite model weights, embeddings, hidden states, or native architecture. The final repaired library contains 26 entries.

The key design test is causal: removing the installed procedure should change which ideas survive.

## The 26-mind inventory

1. **Property Unbundling / Ownership Transfer** — detach a property from its assumed host and transfer ownership literally.
2. **Axiom Fracture / Negative Load-Bearing Synthesis** — negate a hidden assumption and make the negation carry the original goal.
3. **Attentional Shadow Harvesting + Strategic Ambiguity** — promote neglected material and use it before exhaustive explanation domesticates it.
4. **Destructive Compression + Alien Substrate Transference** — preserve a causal invariant while destroying domain identity and solving in a foreign substrate.
5. **Error Axiomatization / Shadow Taxonomy** — find a coherent wrong classification, build the minimum world that makes it literally true, reason rigorously there.
6. **Primitive Deletion / Constitutive Vacuum** — remove a load-bearing primitive without replacement and rebuild around the absence.
7. **Teleological Bootstrap Inversion** — fix a terminal condition first and reconstruct the present so that ending becomes causally inevitable.
8. **Kinetic Dissolution / Metabolic Vector Reorganization** — treat apparent entities as maintained processes and intervene in rates/flows rather than adding objects.
9. **Omission-Field Cognition / Negative Semantic Triangulation** — forbid direct representation and reconstruct a target from independent external constraints.
10. **Cybernetic Circuit Closure + Deutero-Learning** — close the feedback loop sustaining a problem and alter the relational premise that keeps reproducing it.
11. **Ontological Decompilation + Cascading Recompilation** — replace a foundational primitive and rederive genuinely dependent concepts.
12. **Systemic Taxonomic Contagion / Ontological Parasite Protocol** — let a foreign lifecycle colonize host functions; import rules, not imagery.
13. **Oneiric Contamination / Identity Slippage + Retroactive Justification** — assert literal incompatible identity and minimally revise antecedents when consequences require it.
14. **Asynchronous Multi-Axial Shear + Minority-Axis Sovereignty** — run incompatible readings separately, crown the anomalous legitimate one, use others as resistance constraints.
15. **Alien Distance Metrics + Enforced Metric Turnover** — redefine conceptual nearness; retire successful rulers in extended mode.
16. **Selective Cognitive Lesion / Primitive Ablation** — remove one narrow cognitive operation and force compensatory prostheses while other reasoning stays intact.
17. **Synthetic Transducer Array / Downstream Umwelt** — create detectors/sensations for abstract properties and let reflexes change salience/action.
18. **Synthetic Valence Topology / Invented Emotion** — attach an invented affective weighting to a detectable trigger and let it alter selection/preservation.
19. **Lossy Cognition / Forced Aliasing** — destroy dimensions until distant concepts collide, then reconstruct without restoring the lost information.
20. **Procedural Taboo + Aftermath Calculus** — prohibit the direct route and easy workaround; let the goal emerge only as aftermath of another valid process.
21. **Generative Desire / Alien Utility Function** — choose among task-valid candidates using an explicit nonstandard objective.
22. **Descendant Fitness / Progeny Selection** — breed candidates forward and choose the present seed whose lineage has richest future fertility.
23. **Recall Mutation / Reconstructive Memory** — each recall is context-scarred; the scarred descendant becomes the next remembered version.
24. **Observational Crystallization / Attentional Collapse** — deliberate attention fixes a property; unexamined dimensions retain mutation freedom.
25. **Semantic Recoil / Interpreter State Mutation** — later concepts can revise earlier meanings and, if needed, the rule interpreting the sequence.
26. **Meta-Genomic Speciation / Ecosystemic Axiom Breeding** — breed cognitive rules into irreducible offspring whose outputs change the next fitness landscape.

## Distinctions not to collapse

- **Primitive Deletion vs Recompilation:** wound with no replacement vs replacement + dependency rebuild.
- **Synthetic Transducer vs Synthetic Valence:** what becomes detectable vs what matters after detection.
- **Synthetic Valence vs Generative Desire:** affective weighting vs objective function.
- **Teleological Bootstrap vs Descendant Fitness:** fixed future chooses ancestors vs possible descendants choose a present ancestor.
- **Attentional Shadow vs Observational Crystallization:** redirect attention vs attention itself causing commitment.
- **Compression/Transference vs Forced Aliasing:** preserve invariant across substrate vs intentionally destroy information until collisions occur.
