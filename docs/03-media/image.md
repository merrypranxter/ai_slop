# Image Generation

## Objective

Create image weirdness as a **structural consequence**, especially where identity, topology, anatomy, material, and recording medium cannot all remain conventional at once.

## Core stack

### 1. Identity anchor
Preserve selected recognizable features, pose/perspective, silhouette, or reference information so transformation has something stable to violate. The point is not pristine portrait preservation; the anchor creates comparison pressure.

### 2. Governing operator
Choose one actual mechanism: non-orientability, recursive subdivision, reaction-diffusion, phase transition, tensor shear, topology surgery, growth law, property transfer, primitive deletion, etc.

Do not stop at the mathematical noun. State what relation it imposes.

### 3. Anatomical / spatial translation
Map the operator into visible consequences: boundary continuity, folds, holes, duplicated local structures, interpenetration, distributed growth, changing genus, scale recursion, displaced property ownership.

### 4. Material anchor
Give the impossible relation physical weight through a concrete build/material model: silicone, foam latex, cast resin, wet membrane, mineral crystal, magnetic tape, film emulsion, chrome foam, cellular tissue, etc.

### 5. Capture / degradation chain
Make the medium fail for a reason: telecine generation loss, VHS head-switching, chroma bleed, tracking drag, scanline phase, slit-scan temporal accumulation, optical ghosting. A causal chain is stronger than “VHS aesthetic.”

### 6. Controlled residue
Allow errors, seams, asymmetry, and unresolved intersections to remain when they help reveal the pressure between systems.

## High-value operators from the art sources

- **Ontological flipping:** anatomy is the byproduct of the theorem/process.
- **Semantic friction:** specific theorem + tactile material + degraded medium.
- **Symmetry of identity / asymmetry of geometry:** keep recognition while the spatial rule breaks.
- **Reaction-diffusion morphogenesis:** patterns grow as a process rather than painted decoration.
- **Anachronistic friction:** incompatible technological/era logics share one artifact.
- **Pareidolic near-pattern:** structure almost resolves into glyphs/faces/text but remains ambiguous.
- **Observer/medium coupling:** the recording apparatus is damaged by the same transformation it records.
- **Impossible material operator:** physical properties belong to the wrong substrate and must still have consequences.
- **Recursive feedback:** successful artifacts are described/reused/reconditioned rather than cleaned away.

## Iterative experiment pattern

`reference → transform → inspect anomaly → re-use output/reference → same operator or one controlled mutation → repeat`

Record which artifact first appeared on which pass. If an accidental seam becomes stable only after being reconditioned, that is a fossilization event worth tracking.

## Common failure modes

- floating equations on an otherwise normal face;
- generic fractal skin;
- symmetrical “psychedelic portrait” defaults;
- smooth CGI replacing tactile materiality;
- all constraints blending into one harmless aesthetic;
- identity disappearing completely when the experiment needed tension with identity;
- medium degradation pasted on top rather than coupled to the transformation.

## Prompt grammar

Prefer:

`[identity/invariant] + [governing relation] + [translation into anatomy/space] + [physical build] + [capture process] + [what must not be normalized]`

The archived “math slop” docs contain many concrete examples; canonical guidance keeps the mechanism while dropping claims that technical vocabulary bypasses safety or exposes a hidden machine self.
