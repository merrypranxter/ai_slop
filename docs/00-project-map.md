# Project Map

## 1. North star: structured instability

The entire project can be understood as one pipeline:

`ordinary assumption → precise intervention → competing pressures → model/controller attempts resolution → emergent artifact → observe → test → preserve or mutate`

The weirdness is useful when it is downstream of an identifiable operation.

## 2. Four layers of work

### Layer A — Conceptual operators
Rules that change what counts as nearby, possible, stable, identical, remembered, valuable, bounded, causal, or complete. The Temporary Minds library is the deepest catalog here.

### Layer B — Media transduction
Translate a conceptual operator into the degrees of freedom a medium actually has.

- Image: topology, identity, material, composition, spatial binding, texture, signal degradation.
- Video: all image variables plus correspondence, motion, persistence, causality, occlusion, temporal topology.
- Audio: rhythm, meter, timing, pitch/tuning, harmony, spectral shape, source identity, phonetics, form, production space.

### Layer C — Stateful systems
Instead of one-shot prompting, maintain persistent external state: trajectories, mutation ledgers, scars, symbol tables, attractor histories, distance metrics, controller variables.

Systems: Semantic Manifold Game, SMC-1, SRE/Omega-SRE, ESC/NGL, HLC, TOPOS-SRE.

### Layer D — Mechanism research
Study possible representational weak joints: conditioning conflict, binding failure, iteration, compression, tokenization, positional encoding, temporal correspondence, reference-vs-text pressure, etc. This is the DAVID technical-operator track.

## 3. The major families of ideas

### Structured contradiction
Keep multiple incompatible constraints active long enough that the model must invent a compromise. This includes separated musical jurisdictions, identity-vs-topology conflict, material contradictions, and controller rules that cannot all resolve through one default pattern.

### Ontology operations
Change identity, property ownership, primitives, categories, inside/outside relations, object/process status, or dependency graphs.

### Path dependence and memory
A transformation leaves scars. Later states inherit those scars. Includes Recall Mutation, Semantic Recoil, iterative image/audio regeneration, hysteretic controller ideas, and route-based composition.

### Perception and value mutation
Change what gets detected or what gets rewarded: Synthetic Transducers, Synthetic Valence, Generative Desire, Alien Distance Metrics, Attentional Shadow Harvesting.

### Constraint erosion / symbolic compression
State-machine experiments progressively remove linguistic capabilities or replace repeated structure with glyphs and mappings. This is procedural software behavior, not evidence of a model “losing language internally.”

### Material and medium coupling
A mathematical rule becomes tactile through concrete material behavior; recording artifacts are caused by the same transformation rather than added decoratively.

### Iterative artifact fossilization
A weird accident from one pass becomes the conditioning material for the next, turning repair noise, compression artifacts, or mutations into stable features.

## 4. Core artifacts

The project increasingly treats these as more important than a single final prompt:

- **State** — current structural/semantic/music representation.
- **Trajectory** — ordered transformations taken.
- **Ledger** — persistent history and mutations.
- **Operator** — rule causing a state transition.
- **Invariant** — property intentionally held recognizable/stable.
- **Scar** — path-dependent change that persists.
- **Attractor** — recurring stable pattern in a loop.
- **Perturbation** — deliberate state shock used to test or escape a regime.
- **Compiled prompt/spec** — one projection of the current state into a target generator.

## 6. Relationship between the systems

The systems are not competitors; they operate at different levels.

`Temporary Mind` can generate or select an operator.

`Semantic Manifold` can use that operator during a route.

`Controller/HLC` can persist the route and enforce state transitions.

`Media compiler` turns the resulting state into image/video/audio instructions.

`DAVID experiment framework` tests whether a claimed technical mechanism reproduces across conditions.

`GLSL visualizer` can render controller state as an external visualization without pretending it is a literal scan of hidden neural state.

## 7. What is archived rather than canonical

Archived documents contain several recurring overclaims: “the glitch is the machine’s true self,” direct prompt access to hidden tensors, literal RLHF bypass through jargon or Unicode, proprietary architecture claims stated as certainty, and manifesto sections advocating epistemic saturation. These remain useful as history, imagery, or hypotheses, but are not canonical technical guidance.
