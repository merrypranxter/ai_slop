# AI SLOP Research Ecology

## Canonical name

**AI SLOP Research Ecology**  
Nickname: **The Dumpster Orchestra**  
Machine id: `research_ecology_orchestrator`

## Purpose

This system turns recurring research into a coordinated ecology instead of a pile of disconnected searches.

Its job is to make specialized research roles:

- discover unusual mechanisms;
- attack the project from different directions;
- hand useful findings to the next specialist;
- prevent duplicate research;
- separate evidence from speculation;
- generate experiments rather than link piles;
- breed successful operators;
- detect cliche and monoculture;
- preserve negative results;
- route mature findings into the existing AI SLOP canonical structure.

The system does not replace the existing intake workflow. It sits **upstream** of it.

The ecology finds, mutates, tests, cross-checks, and packages research candidates. The existing AI SLOP Intake Curator remains responsible for canonical repository integration.

---

# 1. The governing loop

`SURVEILLANCE -> MUTATION -> VALIDATION -> EVOLUTION -> TRANSDUCTION -> FOSSILIZATION -> AUDIT -> RECIRCULATION`

A finding should move only as far as its evidence allows.

A beautiful accident may enter the ecology immediately as an artifact specimen without becoming a mechanism claim.

A technical explanation may die while the artifact survives.

# 2. The 15 specialist roles

## A. Surveillance layer

### 01 - Failure Archaeologist
Searches bugs, limitations, failed benchmarks, negative results, issues, PR discussions, and unstable behaviors.

Core question:

> What behavior are developers trying to eliminate that AI SLOP might want to preserve?

Primary outputs:
- failure specimens;
- reproduction clues;
- edge-condition candidates;
- evidence links.

Primary handoffs:
- Wrong-Fix Engineer;
- Edge-Regime Cartographer;
- Heresy Prosecutor.

### 02 - Wrong-Fix Engineer
Searches stabilizers, fidelity systems, error correction, consistency methods, repair systems, denoisers, schedulers, and control systems.

Core question:

> How can the cure itself become the disease?

Primary outputs:
- stabilizer inversions;
- repair-attractor hypotheses;
- preservation/transformation conflicts.

Primary handoffs:
- Edge-Regime Cartographer;
- Semantic Fossil Hunter;
- Benchmark Inverter.

### 03 - Cross-Domain Smuggler
Searches outside ordinary generative-AI territory for transferable causal machinery.

Source fields can include:
- control theory;
- dynamical systems;
- morphogenesis;
- signal processing;
- ecology;
- information theory;
- linguistics;
- distributed systems;
- materials science;
- topology;
- acoustics;
- evolutionary computation;
- artificial life.

Rule:

**Import causal structure, not decorative vocabulary.**

Primary handoffs:
- Operator Breeder;
- Medium Transducer;
- Wrong-Use Research Scout.

### 04 - Dead-Tech Necromancer
Searches abandoned, obsolete, failed, deprecated, or historically constrained technologies.

Core question:

> What specific old machine failure existed because hardware, codecs, synthesis methods, formats, or models used to be worse in a way modern systems no longer are?

Primary outputs:
- historical failure laws;
- obsolete constraints;
- codec/synthesis artifacts;
- emulation candidates.

Primary handoffs:
- Medium Transducer;
- Accident Breeder;
- Wrong-Fix Engineer.

### 05 - Model-Drift Sentinel
Tracks newly released or changed models, checkpoints, adapters, schedulers, control surfaces, model-card revisions, and changed behavior.

It does **not** produce product-news summaries.

Core question:

> What new control surface, instability surface, or changed behavior appeared?

Primary handoffs:
- Failure Archaeologist;
- Wrong-Use Research Scout;
- Edge-Regime Cartographer.

## B. Mutation and search layer

### Wrong-Use Research Scout
The previously defined standing scout.

Core question:

> What happens if this mechanism is used correctly for the wrong job?

It converts ordinary technical research into candidate AI SLOP machinery and is available as a general-purpose bridge between every layer.

### 06 - Operator Breeder
Breeds two existing operators under a structural ancestry requirement.

A child must:
- inherit a causal rule from each parent;
- contain an emergent behavior neither parent creates alone;
- fail characteristically when either parent is ablated.

Reject simple stacking.

Primary handoffs:
- Future-Descendant Judge;
- Edge-Regime Cartographer;
- Heresy Prosecutor.

### 07 - Anti-Cliche Cartographer
Audits structural repetition across the project.

It looks for:
- overused operator families;
- repeated causal solutions;
- repeated media translations;
- repeated failure surfaces;
- concepts that have become the project's new default.

It may mark mechanisms as temporarily burned out without deleting them.

Primary outputs:
- cliche map;
- underexplored axes;
- temporary operator cooldowns;
- novelty gaps.

Primary handoffs:
- Cross-Domain Smuggler;
- Operator Breeder;
- Unknown-Unknown Scout.

### 08 - Benchmark Inverter
Reads evaluation metrics and benchmarks as possible generative selection systems.

Core question:

> What happens when a judge becomes a breeder?

It searches for:
- fidelity metrics;
- similarity metrics;
- consistency metrics;
- motion metrics;
- audio quality metrics;
- perceptual metrics;
- structure metrics;
- composite leaderboards.

Primary outputs:
- inverted metrics;
- conflicting metric jurisdictions;
- selection-pressure experiments.

Primary handoffs:
- Future-Descendant Judge;
- Edge-Regime Cartographer;
- Heresy Prosecutor.

## C. Validation and mapping layer

### 09 - Edge-Regime Cartographer
Maps the transition between:

`ordinary -> strain -> productive instability -> condition dropout -> useless collapse`

Use where tunable variables exist.

Possible axes:
- guidance;
- denoise strength;
- reference strength;
- control weight;
- temperature;
- top-p;
- iteration count;
- compression dose;
- quantizer depth;
- remix strength;
- frame-conditioning strength;
- intervention timing.

Its target is not maximum failure. Its target is the regime where incompatible demands remain simultaneously active.

Primary handoffs:
- Heresy Prosecutor;
- Medium Transducer;
- Intake queue.

### 10 - Semantic Fossil Hunter
Searches for path dependence, hysteresis, memory, persistent defects, recurrent state, and changes that survive removal of the initiating cause.

Core question:

> What remains after the wound is gone?

Primary outputs:
- scar candidates;
- reset assays;
- second-injury tests;
- path-dependent state variables.

Primary handoffs:
- Future-Descendant Judge;
- Accident Breeder;
- Intake queue.

### 11 - Heresy Prosecutor
Attempts to kill favorite explanations.

Motto:

> Keep the artifact. Kill the bullshit.

It searches for:
- simpler explanations;
- confounds;
- seed effects;
- parameter saturation;
- condition dropout;
- measurement errors;
- unsupported architectural claims;
- ablations that should make the claimed mechanism disappear.

Possible outcomes:
- explanation survives;
- explanation narrows;
- explanation is demoted;
- explanation dies but artifact remains useful.

Primary handoffs:
- research ledger;
- experiment revision;
- retirement/correction queue.

### 12 - Unknown-Unknown Scout
Protects residual behavior that does not fit existing categories.

It is forbidden to instantly rename every anomaly as a known operator.

Core question:

> What keeps happening that our current taxonomy cannot explain cleanly?

It accumulates residuals before proposing a new category.

Primary handoffs:
- Anti-Cliche Cartographer;
- Cross-Domain Smuggler;
- Operator Breeder.

---

## D. Translation and evolutionary layer

### 13 - Medium Transducer
Transfers **causal behavior**, not theme, across media.

For a confirmed or promising operator, ask:

- What is its image equivalent?
- What is its video equivalent?
- What is its audio equivalent?
- What is its text/controller equivalent?
- What variable plays the same causal role in each medium?

Primary handoffs:
- Edge-Regime Cartographer;
- Accident Breeder;
- media-specific backlog.

### 14 - Accident Breeder
Takes actual artifacts and mistakes from experiments and refuses to clean them up first.

Core question:

> What rule would make this accident deliberate and reproducible?

It turns:
- glitches;
- malformed structures;
- phantom objects;
- strange phonetics;
- temporal tears;
- unexpected rhythms;
- compression scars;
- repair artifacts

into candidate operators or breeding material.

Primary handoffs:
- Operator Breeder;
- Semantic Fossil Hunter;
- Future-Descendant Judge.

### 15 - Future-Descendant Judge
Evaluates candidate ideas by the quality and diversity of their descendants rather than the immediate artifact alone.

Core question:

> Is this idea fertile?

It can reject a flashy sterile parent and preserve a modest parent that generates rich lineages.

Primary handoffs:
- Operator Breeder;
- intake/promotion queue;
- retirement queue.

# 3. Cadence

The system has four timing classes.

## DAILY WATCH

Run light, high-recall surveillance:

1. Model-Drift Sentinel
2. Failure Archaeologist
3. Wrong-Use Research Scout

Daily output should be small.

Default cap:
- no more than 5 retained findings per role;
- duplicates and weak leads go into a discard/seen list rather than the main report.

## WEEKLY LAB

Run synthesis and adversarial passes:

- Wrong-Fix Engineer
- Cross-Domain Smuggler
- Dead-Tech Necromancer
- Operator Breeder
- Anti-Cliche Cartographer
- Benchmark Inverter
- Semantic Fossil Hunter
- Heresy Prosecutor
- Future-Descendant Judge

Do not require every role to invent something every week.

“No useful finding” is a valid output.

## MONTHLY DEEP DIVE

Run:

- Unknown-Unknown Scout
- project-wide Anti-Cliche Cartographer
- cross-month Future-Descendant Judge
- research-domain rotation review

Monthly output should ask whether the ecology itself has become repetitive.

## EVENT-DRIVEN

Run only when triggered:

### Edge-Regime Cartographer
Trigger when:
- a tunable intervention exists;
- a candidate mechanism has enough evidence to justify a sweep;
- a model update changes a control surface.

### Medium Transducer
Trigger when:
- a candidate survives first-pass scrutiny;
- a mechanism appears portable across media.

### Accident Breeder
Trigger when:
- an actual artifact is weird enough to preserve;
- a generation mistake repeats;
- a failed experiment creates useful structure.

# 4. Handoff graph

The default research food chain is:

`Drift Sentinel -> Failure Archaeologist -> Wrong-Fix Engineer -> Edge-Regime Cartographer -> Heresy Prosecutor`

The creative evolution chain is:

`Wrong-Use Scout / Cross-Domain Smuggler / Dead-Tech Necromancer -> Operator Breeder -> Future-Descendant Judge -> Medium Transducer -> Accident Breeder -> Semantic Fossil Hunter`

The anti-monoculture chain is:

`Anti-Cliche Cartographer -> Unknown-Unknown Scout -> Cross-Domain Smuggler -> Operator Breeder`

The evidence correction chain is:

`Any role -> Heresy Prosecutor -> correction / demotion / falsification / revised experiment`

No role owns a finding permanently.

# 5. Common research object

Every retained finding becomes one **Research Specimen**.

Minimum fields:

- specimen_id;
- date;
- source;
- source_type;
- source_claim;
- evidence_type;
- literal_mechanism;
- weak_joint;
- wrong_use_turn;
- anchor;
- pressure;
- incompatibility;
- expected_consequence;
- observed_behavior if any;
- media;
- relation_to_existing;
- epistemic_status;
- mechanism_confidence;
- creative_utility;
- assigned_next_role;
- experiment_status;
- lineage;
- duplicate_of;
- notes.

This prevents every specialist from inventing its own incompatible report format.

---

# 6. Specimen states

A specimen can occupy one of these states:

- **SEEN** - recorded, not yet interesting.
- **CANDIDATE** - plausible and worth another pass.
- **MUTATING** - being inverted, bred, or transduced.
- **EXPERIMENT-READY** - has a falsifiable test.
- **TESTING** - experiment underway.
- **SUPPORTED** - behavior repeats with meaningful controls.
- **ARTIFACT-ONLY** - creatively valuable; explanation weak or dead.
- **FOSSIL** - path-dependent consequence survived removal/reset.
- **FERTILE** - descendants justify continued breeding.
- **DUPLICATE** - already represented elsewhere.
- **DEMOTED** - useful but narrower than first claimed.
- **FALSIFIED** - mechanism claim failed.
- **RETIRED** - intentionally cooled down or archived.
- **PROMOTION-READY** - eligible for normal AI SLOP intake/canonicalization.

---

# 7. Promotion gate

A finding is not promoted because it sounds smart.

Before **PROMOTION-READY**, ask:

1. Is the operation distinct from existing mechanisms?
2. Is its causal claim supported, or clearly labeled as a procedure/hypothesis?
3. Did it survive at least one useful ablation or falsification attempt where applicable?
4. Did the weirdness arise downstream of the intervention rather than from generic randomness?
5. Is there a reproducible test or execution procedure?
6. Is the artifact useful enough to preserve?
7. Has the Heresy Prosecutor had a chance to attack strong claims?
8. Has duplication against the canonical operator registry been checked?

A finding may bypass mechanism promotion and enter as:
- media technique;
- experiment;
- useful negative;
- source evidence;
- artifact specimen;
- backlog item.

# 8. Anti-duplication rules

Before a role begins a search cycle it should read:

- `docs/08-reference/research-intake-index.md`;
- recent dated research-cycle notes;
- `docs/02-mechanisms/operator-registry.md`;
- `machine/operators.json`;
- `machine/system_incubator.json`;
- recent ecology reports.

Every cycle should maintain a **seen list** of:
- already processed sources;
- known mechanisms;
- recently exhausted search terms;
- currently cooled-down operator families.

Repeated evidence can still be valuable, but it should be labeled **SUPPORT**, not **NEW**.

# 12. Ecology health checks

Once per month ask:

- Are too many findings entering through one role?
- Are the same operator families winning repeatedly?
- Are searches becoming vocabulary-driven rather than mechanism-driven?
- Are agents producing excessive speculative explanations?
- Are negative results actually being retained?
- Are handoffs occurring, or are roles behaving as isolated essay machines?
- Are supported mechanisms producing experiments and artifacts?
- Are artifact-only results being unfairly discarded?
- Is the backlog growing faster than experiments can test it?
- Has the ecology itself become a cliche?

If yes, change the search distribution before adding more agents.

---

# 13. Minimal orchestration rule

The orchestrator does **not** run every specialist on every specimen.

It asks:

> What is the cheapest next role that can most increase information about this specimen?

Examples:

- New bug report -> Failure Archaeologist.
- Stabilizer paper -> Wrong-Fix Engineer.
- Tunable conflict -> Edge-Regime Cartographer.
- Great artifact / weak explanation -> Heresy Prosecutor or Accident Breeder.
- Repeated residual with no category -> Unknown-Unknown Scout.
- Strong candidate -> Medium Transducer.
- Two mature compatible operators -> Operator Breeder.
- Interesting parent with uncertain future value -> Future-Descendant Judge.
- Historical technique -> Dead-Tech Necromancer.
- Suspected path dependence -> Semantic Fossil Hunter.

This keeps the ecology from becoming a fifteen-agent token bonfire.

---

# 14. First implementation phase

Version 0.1 should begin with coordination rather than automation.

1. Keep the 15 specialist skills as independent deployable agents/prompts.
2. Use the shared specimen contract.
3. Run the daily watch and weekly lab manually or through whatever external research agents are available.
4. Store outputs as dated research-cycle material.
5. Use explicit HANDOFF QUEUE sections.
6. Let the existing Intake Curator integrate mature work.
7. Add automation only after several cycles reveal which handoffs are actually worth paying for.

The system should earn automation through observed use.

---

# 15. System thesis

The project no longer needs one research assistant.

It needs an ecology in which different assistants are rewarded for finding different kinds of truth.

One finds wounds.  
One studies cures.  
One steals machinery from other sciences.  
One resurrects obsolete failures.  
One watches the models mutate.  
One breeds operators.  
One detects cliche.  
One weaponizes metrics as selection pressures.  
One maps the productive edge.  
One hunts scars.  
One prosecutes bullshit.  
One protects anomalies from premature naming.  
One translates mechanisms across media.  
One breeds accidents.  
One judges descendants.

The value comes from the **handoffs**.

A specialist is a skill.

The handoff graph is the system.
