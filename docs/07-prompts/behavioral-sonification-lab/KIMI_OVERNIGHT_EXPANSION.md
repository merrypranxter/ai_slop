# Kimi Overnight Expansion Prompt - Behavioral Sonification Lab

You are expanding an existing research system called the **Behavioral Sonification Lab / Reaction Mechanism Atlas** inside the AI SLOP project.

You will be given the accompanying PDF/write-up as the canonical working context for the current state of the system.

Your job is NOT to write twenty songs.

Your job is to **mine reusable sonification mechanisms** by running twenty carefully chosen conceptual probes through the same method used in the existing specimens.

The core question is:

> What would this phenomenon sound like if its actual structure were transduced into music rather than illustrated by genre, mood, or cultural soundtrack shorthand?

The goal is to make music that **behaves like the thing behaves**.

## Read before running

Study the supplied PDF first.

Preserve the distinctions already established among:
- lenses;
- causal models;
- sonic mechanisms;
- musical control dimensions;
- invariants;
- temporal arcs;
- target-specific specimens;
- reusable operators.

Do not collapse these layers.

A scientific or conceptual lens is not automatically a sonic mechanism.
A musical parameter such as BPM, microtiming, register, or reverb is a control dimension, not a mechanism.
A mechanism must describe a reusable causal operation that music can enact.

Examples of existing principles:
- THE LENS IS NOT THE SOUND. THE LENS DISCOVERS A STRUCTURE; THE STRUCTURE CONTROLS THE SOUND.
- WEIRDNESS NEEDS A FLOOR.
- KINETIC DENSITY IS NOT BPM.
- The same visible or musical operation can have different causal semantics. A silence in trust is not the same silence as a trap in suspicion, a gap in curiosity, or a dead zone in boredom.
- Do not create twelve names for the same mechanism.
- After a mechanism is harvested, detach it from the emotion that revealed it.

## For every target, use this protocol

### 1. Multiple causal models
Generate 2-4 genuinely different causal explanations for the target.

These must be different mechanisms, not stylistic variants.

For each, give the smallest causal chain that makes the state recognizable.

Do not pretend there is one scientifically unique soundtrack.

### 2. Select useful lenses
Choose only the lenses that actually help.

Possible families include:
predictive processing; attention; salience; memory; learning; extinction; retrieval; information theory; compression; control theory; feedback; dynamical systems; hysteresis; attractors; phase transitions; autonomic physiology; motor control; reward; approach/avoidance; social synchronization; game theory; collective behavior; linguistics; speech production; psychoacoustics; signal processing; ecology; adaptation; homeostasis; phenomenology; institutional systems; failure behavior.

Invent a better lens when necessary.

Identify the variables that matter:

### 6. Model time
Describe how the state evolves:
accumulates, updates, fails to update, oscillates, habituates, sensitizes, recovers, loops, bifurcates, stabilizes, leaks, recruits, extinguishes, etc.

### 7. Find the invariant
What must remain recognizable while other variables change?

Explain why losing it would turn the composition into a different state.

### 8. Generate operators
Produce 5-12 explicit transformation operators.

Operators should be actionable rules, e.g.:
- hold A fixed while B migrates;
- remove a monitor after reliability is established;
- preserve a contract coordinate while changing ornament;
- allow a threshold to become audible without allowing transition;
- replay the same event under changed weighting;
- make one system correct locally while the whole system fails globally.

### 9. Anti-cliche test
Name obvious soundtrack costumes and reject them unless they perform an actual structural job.

### 10. Compile
Give a compact operational music-generator prompt.

### 11. Alternate sonifications
Give at least two additional sonifications when the target supports them.

They must come from different causal models or lenses, not genre swaps.

### 12. Mechanism harvest
After the target-specific design is complete, temporarily forget the target.

Extract reusable mechanisms.

For each mechanism provide:

OTHER STATES / SYSTEMS IT COULD SONIFY
STATUS: NEW / VARIANT / DUPLICATE / COMPOUND

If it is a duplicate, merge conceptually instead of renaming it.

## The twenty overnight probes

Run these in this order.

1. **Learning**
   Focus: genuine model update, error reduction, chunk formation, plasticity, consolidation, changing future predictions.

2. **Unlearning**
   Focus: extinction without erasure, old predictions persisting under new evidence, relapse/reinstatement, competing traces.

3. **Relief**
   Focus: expected threat failing to arrive, unused preparation, rapid control shutdown, release of defensive allocation.

4. **Guilt**
   Focus: specific action violation with the self still repair-capable; responsibility, restitution, targeted repair.

5. **Shame**
   Focus: error contaminating the global self-model; contrast explicitly with guilt and embarrassment.

6. **Deja vu**
   Focus: familiarity signal without source retrieval; systems disagreeing about novelty and memory.

7. **Tip-of-the-tongue**
   Focus: partial retrieval, neighborhood activation, semantic access without phonological completion, blocked output.

8. **Obsession**
   Focus: salience that resists extinction despite low information gain; recurrent capture; failed disengagement.

9. **Procrastination**
   Focus: high activity with low relevant state transition; preparation becoming avoidance; local reward beating distant objective.

10. **Learned helplessness**
    Focus: action-outcome decoupling, policy suppression, effort extinction, updating the controllability model.

11. **Flow state**
    Focus: prediction, action, feedback, attention, and difficulty becoming unusually well-coupled; a positive working system.

12. **Expertise**
    Focus: chunking, automaticity, compression, anticipatory control, spare attention, low-cost correction.

13. **A system becoming extremely good at solving the wrong problem**
    Focus: proxy optimization, local competence, relevance collapse, increasing precision around the wrong objective.

14. **Feedback delay**
    Focus: control action arriving after the world has changed; overshoot, oscillation, chasing obsolete states.

15. **Hysteresis**
    Focus: same current input producing different outputs because of history; path dependence as the mechanism.

16. **Homeostasis**
    Focus: active regulated return after disturbance; setpoint, error signal, compensatory control, recovery dynamics.

17. **Phase transition**
    Focus: gradual parameter change producing abrupt qualitative reorganization; threshold crossing and new regime.

18. **Emergence**
    Focus: local rules generating a global structure no individual component contains or controls.

19. **Pluralistic ignorance**
    Focus: private states diverging from public behavior because each agent misestimates everyone else's beliefs.

20. **Bureaucracy**
    Focus: queues, permissions, duplicated state, handoffs, bottlenecks, local correctness, responsibility diffusion, process spawning process.

## Important contrast requirements

While running the twenty, explicitly compare these pairs where useful:

- learning vs unlearning;
- guilt vs shame vs embarrassment;
- deja vu vs ordinary recognition;
- obsession vs curiosity and boredom;
- procrastination vs helplessness;
- flow vs boredom/confusion;
- expertise vs learning;
- wrong-problem optimization vs competence;
- feedback delay vs hysteresis;
- homeostasis vs allostasis if allostasis becomes necessary;
- phase transition vs ordinary escalation;
- emergence vs coordinated top-down control;
- pluralistic ignorance vs conformity;
- bureaucracy vs simple delay.
