# Mechanisms

This section is the reusable machinery shelf. A mechanism belongs here when it describes **an operation that changes what the generator/controller has to resolve**, rather than a finished aesthetic.

## Families

- [`operator-registry.md`](operator-registry.md) — cross-media operator map, deduplicated by function.
- [`david-technical-hypotheses.md`](david-technical-hypotheses.md) — technical roundtable mechanisms that require experimental validation.

## Registry fields

Each reusable mechanism should eventually carry:

`name → scope → status → attacked assumption → operation → expected consequence → amplification → failure mode → validation → source`

## Promotion rule

An evocative phrase is not automatically an operator. It graduates when the rule can be stated without the aesthetic costume and still changes what outputs become legal, likely, or selectable.
