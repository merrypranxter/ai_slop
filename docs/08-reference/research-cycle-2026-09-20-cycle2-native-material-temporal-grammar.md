# F17 - Endogenous Activation Grafting

**Source family:** Cassano et al., *Look But Don't Touch with Sparse Autoencoders for Unlearning in Diffusion Models* (2026).

**Classification:** new technical intervention family; validator architecture; diffusion implementation.

## What the source contributes

The source separates **where a concept is detected** from **how the model is altered**. SAE features are used to locate concept-associated spatial patches, but the intervention does not decode or push those SAE features directly. Instead, detected patch embeddings are replaced with **undetected embeddings already present in the same feature map and same forward pass**.

The reported comparison matters because direct SAE manipulation often produced heavy artifacts, while Patch Embedding Replacement reduced those artifact rates substantially in the tested setups.

## What is actually new for AI SLOP

The project already has feature surgery, property transfer, taxonomic contagion, and activation steering. The distinct extension is:

1. **Detect with one mechanism.**
2. **Act with another.**
3. **Source the actuator material from the host system's own current activation ecology.**

This makes intervention provenance part of the operator.

## Candidate mechanism

**Endogenous Activation Grafting**

Detect a jurisdiction using a classifier, SAE, attention map, probe, residual, or other signal. Modify only by transplanting internal material that the current generative pass already produced.

### Candidate donor rules
- random undetected donor;
- nearest native neighbor;
- farthest semantic neighbor;
- earlier-timestep self;
- later reconstructed self;
- second-prompt donor;
- maximum detector disagreement donor;
- cyclic donor permutation;
- cross-layer donor.

### Candidate wrong-use variants
- replace background with object-bearing activations;
- transplant material properties across semantically incompatible regions;
- preserve the target and graft its surrounding activation ecology instead;
- dilate the donor jurisdiction rather than the target mask;
- cross-generation donor swaps;
- use old activations as developmental fossils.

## New architecture principle

**Detector-Actuator Separation**

A representation that is useful for detecting or localizing a concept is not automatically a safe or useful actuator.

Future interpretability work should independently test:
- detection;
- localization;
- reconstruction;
- intervention.

Success in one role is not evidence for the others.

## New provenance concept

**Donor Jurisdiction**

Record which internal positions, timesteps, layers, generations, or specimens are legally allowed to supply replacement material.

## Current status

**High-value prototype candidate. Not canonical yet.**

# F18 - Neural Particle Automata: update, not duplicate

**Source family:** Pajouheshgar et al., *Neural Particle Automata* (SIGGRAPH 2026).

**Classification:** known substrate with a stronger implementation/identity framing.

NPA already exists in the repo under:
- Moving-Neighborhood Causal Rewiring;
- functional-scar / moving-neighborhood combinations;
- developmental substrate comparisons.

The Cycle 2 delta is not "discover NPA." The useful update is that particle identity can now become an explicit measurement axis.

## New experimental framing

**Morphological Ship of Theseus**

A form may visually regenerate while:
- original particles are gone;
- hidden state has turned over;
- local rules persist;
- lineage has changed;
- behavior returns.

That means future regeneration work should separately track:
- particle survival;
- hidden-state survival;
- rule survival;
- morphology recovery;
- behavior recovery;
- lineage continuity.

## New candidate experiment

Exchange 10%, 25%, 50%, and 90% of particles between two trained organisms while preserving their states. Measure whether identity follows:
- matter;
- rule;
- geometry;
- neighborhood;
- history.

## Disposition

**Update existing NPA / Silent Scar / identity work. Do not create a duplicate NPA operator.**

# F19 - Temporal Grammar Preservation

**Source family:** Liu et al., *Beyond Consistency: Preserving Temporal Structure in Zero-Shot Video Editing* (2026).

**Classification:** new temporal regulator family; video adapter; hierarchical anchoring protocol.

## What the source contributes

The work separates ordinary frame-to-frame consistency from **temporal structure**:
- detect semantic clip boundaries;
- choose an anchor within each clip;
- enforce strong inheritance within clips;
- allow sparse adjacent-clip exchange through alternating pairings late in denoising.

The project already studies drift, leakage, scars, and temporal schedules. The new distinction is that **phase boundaries, intra-phase inheritance, and inter-phase negotiation are separate operations.**

## Candidate mechanism

**Semantic Epoch Partitioning**

Split a trajectory when its internal representation changes enough. Each epoch gets:
- a boundary;
- an anchor;
- an inheritance policy;
- a bridge policy to neighboring epochs.

## Candidate mechanism

**Alternating Temporal Bridge**

Instead of letting every epoch communicate uniformly, exchange information across different neighboring pairings on alternating steps or schedules.

## Wrong-use / art variants
- least-representative anchor;
- shuffled anchors;
- future texture inherited backward;
- event order preserved but durations exchanged;
- background grammar preserved while subject grammar is scrambled;
- audio section boundaries governing video epochs;
- anchor authority decays with age.

## New evaluation warning

A video can be smooth, identity-stable, and still destroy:
- event boundaries;
- order;
- duration;
- semantic transitions;
- callbacks or rare events.

Temporal evaluation therefore needs more than adjacent-frame stability.

## Current status

**New regulator candidate. Paper-level implementation gate remains.**

# F20 - TADA bottleneck localization: implementation upgrade

**Source family:** Staniszewski et al., TADA.

**Classification:** existing steering family, stronger implementation and geography evidence.

TADA is already present in the repo. Cycle 2 adds two important upgrades:

1. The work reports musical controls concentrated in small subsets of cross-attention layers in the tested architectures.
2. Public code, controllers, evaluations, and Hugging Face artifacts make this a much more practical experimental surface than our earlier abstract notes implied.

## Candidate adapter term

**Semantic Bottleneck Mixer**

Treat each causally localized musical layer set as a channel strip with:
- signed strength;
- schedule;
- modulation source;
- preservation budget;
- collision partner.

This is not a new canonical steering operator. It is an executable control surface.

## High-value experiments
- incompatible directions in different bottlenecks;
- positive and negative versions of one concept across layers;
- diffusion-step oscillation;
- particle-density-controlled steering strength;
- SAE direction vs contrastive direction collision;
- non-monotonic steering search.

## Method consequence

Steering records should include **layer geography** before interpreting direction strength.

## Current status

**Update TADA/audio notes and use as testbed; do not duplicate activation steering.**

# F21 - Exceptional-Point Harvesting

**Source family:** Maeda, Nakamura, Takayanagi, PT-symmetric BCFT work (2026), plus the broader exceptional-point / non-Hermitian lineage.

**Classification:** speculative mathematical transplant.

## What is useful

The artistic idea is not "use opposite controls." The useful mechanism is to search for a coupled parameter regime where:
- two symmetry-related modes coalesce;
- the balanced regime loses its former stability/class;
- qualitatively different trajectories appear across the critical region.

## Candidate protocol

**Exceptional-Point Harvesting**

Create paired antagonistic jurisdictions, vary their common strength, and densely sample:
- below the critical region;
- near mode coalescence;
- immediately after symmetry breaking.

Only keep the name if the prototype exhibits a genuine coupled-system signature that cannot be reproduced by an ordinary if/else threshold.

## Potential embodiments
- paired gain/loss oscillators mapped to image or audio;
- opposite hue or geometry drives at mirrored boundaries;
- paired layer steering with opposite signs;
- attraction/repulsion across particle species;
- opposite guidance across alternating video epochs.

## Relation to existing work

Closest existing project families:
- Non-Normal Flare-and-Return;
- Structured Instability;
- Separated Jurisdictions;
- conflicting controllers;
- phase-transition harvesting.

## Current status

**Speculative backlog item only.**

# Method upgrades from Cycle 2

## SAE / interpretability role separation

For any learned representation or sparse feature set, score separately:
1. **Detection** - can it identify the target?
2. **Localization** - can it identify where/when it appears?
3. **Reconstruction** - does decode/reconstruction preserve native statistics?
4. **Intervention** - does changing it causally produce the intended result without collateral damage?

Do not transfer confidence across columns.

## Native-distribution preservation

For internal interventions, add a **native-manifold / activation-distribution check** where practical. Compare transplant-based interventions against synthetic or decoded directions.

## Regeneration identity decomposition

For particle/cellular systems, separate:
- matter identity;
- hidden-state identity;
- rule identity;
- morphology;
- function;
- lineage.

## Temporal structure validation

For video/sequence systems, measure separately:
- adjacent smoothness;
- identity consistency;
- semantic epoch boundaries;
- event order;
- duration;
- cross-epoch continuity;
- rare-event preservation.

## Steering geography

Record **where** a direction is applied, not only direction and magnitude:
- layer;
- layer set;
- timestep window;
- spatial jurisdiction;
- schedule.

# Strong combination signals created by Cycle 2

1. **Endogenous Activation Grafting + Instability-Gated Intervention**
   - Detect local failure intervals, then repair or mutate them using native donor activations rather than synthetic steering.

2. **Endogenous Activation Grafting + Semantic Fossil Instrument**
   - Persist donor activations and donor-jurisdiction history as route fossils.

3. **Detector-Actuator Separation + EraseSAE / SAE surgery**
   - Use sparse features for sensing; compare multiple independent actuators before claiming a controllable concept.

4. **NPA + Functional Scar / Silent Scar**
   - Test whether second-injury response follows particle identity, hidden state, rule, or morphology.

5. **NPA + Localized Law Carriage**
   - Let rule parameters travel inside mobile particles rather than only in a continuous field.

6. **Semantic Epoch Partitioning + Controlled Temporal Leakage**
   - Vary leakage within epochs separately from leakage across epoch boundaries.

7. **Semantic Epoch Partitioning + Trajectory Fossils**
   - Fossilize failed or mutated epoch anchors and reinsert them into later routes.

8. **TADA Bottleneck Mixer + cross-modal transducers**
   - Use particle density, visual motion, or other non-audio signals to modulate localized audio steering.

9. **Exceptional-Point Harvesting + Non-Normal Flare-and-Return**
   - Compare transient amplification against genuine mode-coalescence threshold behavior instead of treating every dramatic jump as the same instability class.
