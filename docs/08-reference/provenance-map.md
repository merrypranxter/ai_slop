## Semantic systems

### `ai_readable/semantic_systems/03-semantic-engineering.md`, `04-semantic-trap-engineering.md`
Feed prompt-proxy steering, semantic recursion/state-machine concepts, decay systems, symbolic compression, domain pivots, and the historical Omega-SRE architecture. Canonical docs strip claims that these prompts literally expose hidden tensors or bypass safety.

### `05-external-state-controller.md`
Feeds ESC/NGL separation, state register, trigger loop, matrices, domain sets, failure modes, and controller-worker protocol.

### `06-hard-logic-controller.md`
Feeds software-first HLC: persistent JSON state, structural/semantic similarity measures, attractor detection, decay/rebirth, operation blocks, diagnostic audit log.

### `07-latent-space-game.md`
Feeds SMC-1 state matrix, path ledger, transduction pipeline, navigation operators, transformation kernels, distance metrics, recoil/collision/degeneration ideas.

### `08-semantic-manifold-game-design-specification-v0.1.md`
Primary design reference for the Semantic Manifold Game. Critically establishes that “latent space” is a useful lie and the app should manipulate an external operational analogue; defines state + trajectory + history + interpretation as the real artifact.

### `09-topos-sre-user-manual.md`
Feeds practical TOPOS-SRE behavior, local-first cost model, perturbations, diagnostics, experiment cookbook, attractor/decay/tension interpretation, and lab-note practice.

### `01-ghost-glsl-roundtable.md`
Feeds GLSL/state visualization ideas, controller-to-shader mapping, fossil/feedback concepts, and a large backlog of theatrical/speculative ideas. Safety-bypass and exploit rhetoric is archive-only.

### `02-weight-manipulation.md`
Feeds the local/open-model intervention track: activation steering, logit bias, weight editing, representation visualization. Keep it separate from prompt-only simulation.
