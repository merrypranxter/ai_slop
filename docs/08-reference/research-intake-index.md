# AI SLOP Research Intake Index

This index tracks research-scouting material before it is promoted into canonical mechanisms or systems.

## Current rule

Research arrives here first. Each cycle should preserve:

- source claims;
- what actually changed for AI SLOP;
- candidate mechanisms or adapters;
- possible cross-cycle combinations;
- negative / low-yield searches;
- open questions;
- evidence limitations.

Do not rebuild the project around one exciting paper. Wait for convergence.
