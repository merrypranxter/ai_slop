# AI SLOP Candidate Mechanisms Queue
## Cycle 2 - Native Material / Temporal Grammar / Dynamic Topology
### 2026-09-20

These are backlog candidates and method upgrades. They are not canonical operators yet.

---

## C26. Endogenous Activation Grafting

**Core idea:** detect an internal target with one representation, but modify it using activations already produced by the current model pass.

**Source family:** PER / Look But Don't Touch.

**Potential knobs:** detector, threshold, layer, timestep, target mask, donor jurisdiction, donor selection rule, replacement frequency, dilation.

**Key controls:** synthetic steering; decoded SAE replacement; random native donor; no-op; matched spatial extent.

**Primary measurements:** artifact rate, target migration, activation-distribution shift, spatial repetition, downstream collateral change, route reproducibility.

**Current class:** actuator / intervention family.

---

## C27. Detector-Actuator Separation

**Core idea:** the representation that senses a concept need not be the mechanism that edits it.

**Required independent evaluations:** detection, localization, reconstruction, intervention.

**AI SLOP use:** compare multiple actuators behind the same detector before calling a feature a control knob.

**Current class:** architecture principle / validator.

---

## C28. Donor Jurisdiction

**Core idea:** explicitly define which internal states are legal sources of replacement material.

**Possible donor jurisdictions:** same layer, same timestep, same sample; earlier self; later self; second generation; second prompt; cross-layer; semantic opposites.

**Required provenance:** donor coordinates, layer, timestep, specimen, detector state, selection rule.

**Current class:** provenance contract / operator parameter.

---

## C29. Semantic Epoch Partitioning

**Core idea:** divide long trajectories into semantically coherent epochs with separate boundaries, anchors, inheritance, and cross-epoch negotiation.

**Potential knobs:** boundary threshold, anchor method, anchor authority, epoch length, merge ratio, bridge start time.

**Controls:** fixed-length clips; single global anchor; no cross-epoch bridge; random boundaries.

**Current class:** temporal regulator.

---

## C30. Alternating Temporal Bridge

**Core idea:** exchange information across changing neighboring epoch pairings rather than maintaining a uniform temporal graph.

**Potential knobs:** pairing graph, schedule, bridge strength, directionality, late/early activation.

**AI SLOP variants:** nonlocal pairings, cyclic bridges, reversed bridge order, future-to-past inheritance.

**Current class:** temporal intervention.

---

## C31. Semantic Bottleneck Mixer

**Core idea:** identify minimal functional layer sets for musical concepts, then treat those sets as separately schedulable control channels.

**Source family:** TADA.

**Status note:** steering itself is not new; this is an adapter built from localized layer geography.

**Controls:** same direction all layers; bottleneck only; outside-bottleneck only; matched norm; step schedule.

**Current class:** audio adapter / testbed.

---

## C32. Morphological Ship of Theseus Assay

**Core idea:** visible regeneration does not determine whether identity persisted.

**Required identity dimensions:** particle survival, hidden-state survival, rule survival, morphology, function, lineage.

**Primary experiment:** controlled particle exchange between separately trained organisms at 10%, 25%, 50%, and 90%.

**Current class:** identity validator / ALife protocol.

---

## C33. Exceptional-Point Harvesting

**Core idea:** search around a coupled-system mode-coalescence / symmetry-breaking boundary rather than using an arbitrary threshold switch.

**Minimum prototype:** paired complex oscillators or another explicitly non-Hermitian system with measurable eigenvalue/mode behavior.

**Required falsification:** compare against an ordinary hard threshold with matched output range.

**Promotion gate:** only retain as distinct mechanism if the critical region creates reproducible structure that depends on the coupled dynamics.

**Current class:** speculative mathematical transplant.
