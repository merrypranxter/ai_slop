# AI SLOP Candidate Mechanisms Queue
## Closed-loop intervention / instability / symbiosis intake — 2026-09-20

These are backlog candidates from the Perplexity cycle. None are canonical operators yet.

## C20. Sparse Autotelic Perturbation

**Source family:** CARL / Artificial Experimentalist.

**Core idea:** a controller observes a live evolving system, pursues a high-level goal, is restricted to small local actions, and pays a cost for every intervention.

**Important difference from generic feedback:** the controller is rewarded for making the substrate sustain the result with as little continued correction as possible.

**Potential knobs:** goal descriptor, intervention radius, action magnitude, add/remove/no-op set, cost, cost schedule, post-control viability window.

**Primary metric:** target achievement under intervention cost.

**Secondary metric:** **Intervention Debt** — how much continued correction is required after the desired state appears.

**Controls:** open-loop matched actions; random matched-magnitude actions; zero-cost controller; no-intervention baseline.

**Current class:** regulator / experimental architecture.

---

## C21. Instability-Gated Intervention

**Source family:** high-CFG inversion / SkipInv.

**Core idea:** compute a local stability/convergence signal over a generation or inversion trajectory and attach interventions only to failing intervals.

**Potential signals:** fixed-point residual, reconstruction error, contraction estimate, conditional/unconditional displacement, cross-attention entropy.

**Potential actions:** relax, amplify, alternate, freeze, splice, or reroute guidance at unstable steps.

**Artifact record:** preserve unstable interval coordinates and intervention history as **Trajectory Fossils**.

**Controls:** same total intervention dose applied uniformly; random-timestep intervention; ordinary SkipInv repair; no intervention.

**Current class:** diagnostic + candidate technical operator.

---

## C22. Evolvable Jurisdiction Stack

**Source family:** Programmable Cellular Automata.

**Core idea:** local, global, and decision modules are explicit code units with independent mutation/crossover.

**Potential knobs:** number of modules, visible variables, update synchrony, module mutation rates, global-statistic vocabulary, decision logic, code-size limits.

**Key failure:** global modules can become answer-leaking shortcuts or metric exploits.

**Required validator:** track information access and compare morphology/behavior, not score alone.

**Current class:** architecture pattern / generator-evolution substrate.

---

## C23. Repair–Corruption Frontier

**Source family:** code-correctness steering study.

**Core idea:** never summarize intervention quality with one average score when the same operator can repair bad states and corrupt good ones.

**Required cells:** bad->good, bad->bad, good->good, good->bad, degeneration.

**Required controls:** matched-norm random direction, dose sweep, independent gate/detector, held-out evaluation.

**Current class:** validator / mandatory measurement contract.

---

## C24. Symbiotic Fitness

**Source family:** Barricelli revival / SymBa.

**Core idea:** fitness can belong to a pair or consortium when the useful capability exists only in interaction.

**Qualification tests:**
- order sensitivity;
- pair specificity;
- persistence after separation;
- shuffled-partner failure;
- reproducible offspring effect;
- no equivalent solo behavior.

**Not the same as:** averaging, blending, simple crossover, or scoring two artifacts independently.

**Current class:** selection hypothesis / breeding extension.

---

## C25. Localized Law Carriage

**Source family:** Flow Lenia.

**Core idea:** a moving structure carries its own local transformation parameters through a shared field and can blend/exchange them on contact.

**Disposition:** do not promote as a new operator. Use as a substrate/implementation of Property Unbundling + Separated Jurisdictions.

**Current class:** implementation pattern / substrate.

# Promotion rule

None of C20-C25 graduates until:
1. there is a runnable implementation or faithful minimal analogue;
2. the claimed signature survives a matched ablation;
3. creative utility is separated from mechanism confidence;
4. the effect is reproducible across more than one convenient case;
5. overlap with existing operators is explicitly tested.
