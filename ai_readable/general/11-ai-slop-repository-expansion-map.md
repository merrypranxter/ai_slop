I inspected the repository tree and concentrated on the canonical AI material, machinereadable registries, semantic controllers, Temporary Minds, experimental method, media
transduction documents, backlog, and representative source-lineage files. I made no changes
to the repository; the strongest expansion is not “more prompts,” but turning this unusually
coherent conceptual library into an executable ecology of operators, experiments, archives,
and generative artworks.

AI SLOP Expansion Map
What it already is
AI SLOP is better understood as a laboratory for structured cognitive mutation than as a prompt
collection. Its central cycle is:
ordinary assumption → precise intervention → competing pressures → attempted
resolution → artifact → observation → test → preservation or mutation

The canonical system currently contains 26 Temporary Minds, a broader cross-media operator
registry, several external-state semantic controllers, media-specific translation methods, and an
unusually good distinction between creative usefulness and confidence in the explanation of
why something worked.
Four layers recur throughout the repository:
Conceptual operators: Mutations of identity, distance, attention, memory, value, causality,
categories, completion, and selection.
Media transduction: Converting those mutations into actual image, video, audio, material,
typography, topology, rhythm, or shader behavior.
Stateful systems: Maintaining trajectories, scars, symbol tables, attractors, retired
operators, and mutation histories outside the model.

Mechanism research: Controlled investigation of binding failures, conditioning conflicts,
compression, positional effects, reference pressure, and actual local-model interventions.
The machine-readable layer already makes this more than literary theory.
machine/operators.json can become the seed of a runtime registry rather than merely an
index.

Main missing layer
The largest gap is connective tissue. The repository describes operators, validators, controllers,
ledgers, compilers, and state transitions, but they do not yet form one runnable environment in
which a user can:
1. Install an operator.
2. Generate several candidates.
3. Observe what structurally changed.
4. Compare against a baseline.
5. Place the result in a behavioral archive.
6. Breed or mutate it.
7. Compile it into another medium.
8. Preserve its ancestry and scars.
This matters because computational creativity normally separates generation from evaluation,
while conceptual blending adds explicit input spaces, correspondence, selective projection,

and emergent blend structure [1] [2] . AI SLOP already contains richer mutation procedures than
many computational-creativity systems; what it lacks is a consistent runtime for executing and
comparing them.

The Operator Workbench
The most natural major project is an Operator Ecology Workbench: a browser application
where every operator is executable, inspectable, breedable, and testable.

Runtime objects
Each experiment would manipulate these objects:
Task: The human’s actual requirement.
State: Current ontology, constraints, symbols, media variables, and unresolved conflicts.
Operator: A transition procedure.
Invariant: What must survive the transition.
Candidate family: Multiple results, not one lucky artifact.
Behavior descriptor: Measurable properties used to classify the result.
Scar: A state change that persists after its initiating condition disappears.
Archive cell: A niche containing the strongest artifact found for one behavioral profile.
Lineage: Parent operators, artifacts, mutations, and selection events.
Compiler: A translator from conceptual state into text, image, GLSL, audio, or video
instructions.

Execution cycle
1. Generate an ordinary baseline.
2. Select one operator and explicit strength.
3. Produce several candidates.
4. Run hard validators before aesthetic ranking.
5. Extract behavioral descriptors.
6. Place candidates into an archive.
7. Let the user preserve, reject, breed, or mutate them.
8. Compile selected states into a target medium.
9. Remove the operator and test whether claimed scars persist.
10. Save the complete lineage as a reproducible experiment.
This would make “operator burnout,” “conceptual allergy,” and “afterlife” computationally real.
Novelty search rewards behavioral difference rather than resemblance to an ultimate target,
specifically to avoid deceptive objective landscapes [3] [4] . MAP-Elites extends that idea by

maintaining many high-performing but qualitatively different solutions across user-selected
behavioral dimensions instead of returning one winner [5] .

Operator breeding
The repository’s Structural Ancestry Requirement is strong enough to support an actual
operator genetics system. Conceptual blending systems distinguish input spaces, shared
structure, selective projection, completion, and elaboration; importantly, the blend may
contain emergent relations that appear in neither input [1] [6] .
A breeding engine could therefore require:
Two parent operators with different intervention targets.
A declared shared invariant.
One rule inherited from each parent.
One incompatibility that offspring must resolve.

An emergent transition rule not reducible to sequential application.
An ablation showing that removing either parent destroys the offspring’s characteristic
behavior.
Example offspring:

Fossilized Taboo
Parents: Procedural Taboo + Recall Mutation.
A forbidden direct operation cannot be performed, but each failed attempt mutates memory.
Eventually the accumulated memory scars create an indirect path that did not exist at the
beginning.

Migratory Sensorium
Parents: Synthetic Transducer + Property Unbundling.
A detector’s sensory ownership moves among entities. Each new host experiences the same
signal differently because its available actions differ.

Crystalline Recoil
Parents: Observational Crystallization + Semantic Recoil.
Attention fixes an interpretation temporarily, but later evidence can alter the rule that made
the fixation possible. The old interpretation remains physically present as a fossil rather than
being overwritten.

Jurisdictional Organism
Parents: Separated Jurisdictions + Kinetic Dissolution.
Different metabolic flows obey different legal systems. The “organism” exists only as
negotiations among incompatible maintenance regimes.

The artistic leap is to let shader state affect the semantic controller in return. Dense regions
might reduce available language, vortices might change conceptual distance, and crystallized
areas might become temporarily immutable.

Artificial-life direction
The operator system is highly compatible with artificial life because it already treats ideas as
processes with mutation, inheritance, niches, scars, and speciation. Lenia is a continuous
cellular-automaton family known for producing diverse, resilient, moving autonomous
patterns; its original survey reported more than 400 identified forms across 18 families [7] .
Flow-Lenia adds mass conservation, multispecies behavior, and emergent evolutionary
dynamics [8] .
A project called Semantic Lenia could assign each conceptual operator:
A convolution kernel describing what state regions it can influence.
A growth function describing conditions under which it strengthens or decays.
A conserved resource such as attention, descriptive bandwidth, or interpretive certainty.
A mutation rule.
A compatibility matrix with other operators.
A phenotype compiled into text, sound, or imagery.
This should not pretend that semantic concepts literally behave like cells. It would be an
external dynamical artwork whose state is periodically interpreted by an LLM.
Useful implementation references include HexLife, which combines browser-based cellular
automata, multiple worlds, WebGL rendering, and evolutionary exploration; Petri, which
breeds multiple Lenia universes using MAP-Elites; and Primordia, which combines Lenia,
Physarum, particle life, and Gray–Scott systems in a GPU artificial-life environment. These are
implementation references rather than evidence that their conceptual frameworks match AI
SLOP.

Artwork families

Museum of Retired Metrics
Every room contains artifacts produced under a different alien distance metric. Once a metric
yields a successful family, it is permanently retired, and the room becomes inaccessible except
through its descendants.

The Absent Orchestra
Omission-Field Cognition reconstructs an unnamed musical object through rhythm, spectral
holes, performer behavior, room response, and the reactions of other instruments. No channel
may directly state the missing object.

Error Zoology
A classifier’s coherent near-errors become literal species definitions. Each species receives a
metabolism, morphology, habitat, failure behavior, and evolutionary history consistent with
the misclassification.
Research on AI art has found that artists actively use model inconsistencies, imprecise
representations, overinterpretation, and technological failures to create ambiguity rather than
treating them only as defects [9] . This supports the repository’s Structural-Error Sieve: preserve
coherent errors, not indiscriminate corruption.

Codec Organs
Compression blocks, chroma subsampling, ringing, quantization, motion vectors, and packet
loss become anatomical functions. A body does not receive a JPEG texture; it grows,
remembers, heals, and decomposes according to codec behavior.
Algorithmic-information approaches have explicitly connected novelty generation to lossy
compression and described generative systems as analogous to decompressors [10] . Glitch
theory likewise treats file formats and codec errors as material agencies rather than arbitrary
visual overlays [11] [12] .

Semantic Cemetery
Deleted concepts remain as gravestones whose positions alter navigation. Removing an idea
therefore reduces descriptive clutter but changes the shape of every later route.

Noncommutative Film Lab
Apply transformation A and then B, followed by B and then A. The film consists of the growing
difference between those histories, especially after occlusion, reappearance, identity
reassignment, or temporal compression.

The Audience Is Weather
Several simulated audiences observe the same evolving piece. Their disagreement becomes
wind, erosion, phase cancellation, or mutation pressure, but no audience directly controls the
piece.

SLOP Radio
A semantic controller broadcasts its state as generative sound. Conflict becomes polyrhythmic
jurisdiction, certainty narrows tuning, forgotten concepts survive as weak carrier frequencies,
and operator burnout permanently removes an instrument-generation rule.

Quasicrystal Cognition
Temporary Minds are arranged according to an aperiodic tiling rather than a sequence.
Neighboring tiles determine which operators may combine, while local patterns recur without
global repetition.
This offers a strong connection to your interest in quasicrystals: the installation could preserve
local recognizability while making global operator recurrence impossible to reduce to a loop.

Browser of Counterfactual Fossils
Every abandoned branch leaves a small executable residue. Users can click the residue to
reveal how the current artifact would collapse if that rejected possibility had never constrained
it.

The Work That Hates Being Named
An anomaly begins as an unlabelled behavior. Each successful label causes the anomaly to
migrate into another medium or state dimension, operationalizing Strategic Ambiguity as an
adversarial relationship with classification.

Activation Addition constructs steering vectors from differences between prompt-induced
activations and injects them during inference; published results show that this can alter highlevel output properties while often preserving unrelated performance [13] . ROME instead edits
feed-forward weights associated with factual recall and evaluates whether the change remains
specific while generalizing to relevant contexts [14] .
Sparse-space steering is especially relevant to Synthetic Transducers and Selective Cognitive
Lesions because raw activation directions are often entangled. Current research explores
steering in sparse feature spaces precisely to obtain more interpretable and targeted
interventions [15] [16] .

These should become an explicitly separate white-box track inside the workbench. Promptonly runs, API-mediated generations, and actual hidden-state interventions should never share
the same mechanism labels.

A metacreative controller
The support architecture can become a real metacreative controller that examines its own
search process rather than only scoring outputs. Computational metacreativity research
defines this in terms of self-reflection and self-control: the system observes and adjusts its
creative standards or process [17] .
The controller could periodically ask:
Which operators dominate the archive?
Which descriptors have become easy to optimize?
Which apparent novelties are surface variations of the same skeleton?
Which rejected artifacts have unusually fertile descendants?
Which validators reject nearly everything?

Which operators only work with one model?
Which human selections contradict automatic scores?
Has an alien metric become an ordinary metric through repeated use?
Is the archive expanding, or merely polishing occupied niches?
Should the system mutate an operator, a validator, a distance metric, or the task
representation?
This would implement Meta-Genomic Speciation at the appropriate level: not “the AI became
creative,” but “the external search controller modified which creative procedures are available
and how their success is measured.”

Evaluation expansion
The existing 0–3 benchmark dimensions should remain, but each run could also record:
Causal delta: Difference from baseline attributable to the operator.
Task survival: Percentage of hard task requirements retained.
Operator identifiability: Whether blinded evaluators can infer the installed operator.
Literal consequence depth: Number of downstream decisions changed by the mutation.
Archive novelty: Distance from previous behavioral signatures.
Ancestry irreducibility: Performance loss when either parent is ablated.
Scar persistence: Whether a change survives removal of its initiating condition.
Order sensitivity: Difference between A→B and B→A.
Cross-model portability: Whether the recognizable mutation recurs across models.
Compiler fidelity: Whether an abstract state produces corresponding behavior in different
media.
Evaluator disagreement: Human/model/rule-based ranking divergence.
Descendant fertility: Number of structurally distinct valid offspring within a fixed
generation budget.
A first serious benchmark could test all 26 Temporary Minds across the repository’s five
standard tasks, three models, and five runs per condition. That creates 1,950 operator runs plus
75 ordinary baselines, while remaining small enough to analyze as families rather than isolated
screenshots.

Research questions
The richest questions are not “does this prompt make the model weirder?” They are:
Which operators create recognizable cross-task signatures?
Which pairs produce irreducible offspring rather than stacked effects?
Which minds merely rename ordinary brainstorming procedures?
Which models collapse separated jurisdictions into stylistic blending?

Can operator identity be detected from outputs without seeing prompts?
Does operator success transfer from text to image or audio compilation?
Do human evaluators and embedding-based novelty measures identify the same clichés?
Can archive pressure produce genuinely new structural families, or does it optimize
superficial difference?
Which scars persist after their originating instruction disappears?
Does model-generated self-evaluation domesticate the anomalies it is asked to inspect?
Can a human detect more valuable stepping stones than a fixed novelty metric?
Interactive evolutionary work has already combined human selection with novelty search to
discover stepping stones that objective optimization misses [18] . That makes a mixed-initiative
model especially appropriate here: the software manages archives and reproducibility, while
the artist protects strange candidates that automatic evaluators would eliminate.

First build sequence
Phase A: Registry compiler
Convert operators, validators, Temporary Minds, protocols, and media adapters into one
validated schema. Add automatic checks for missing falsification tests, hidden metaphor
escapes, undocumented state effects, and duplicate functional signatures.

Phase B: Text laboratory
Build a local browser interface with baseline generation, operator installation, candidate
families, side-by-side state diffs, scoring, lab notes, and exportable experiment bundles. Begin
with five sharply distinct operators rather than all 37: Primitive Deletion, Alien Distance,
Synthetic Transducer, Recall Mutation, and Procedural Taboo.

Phase C: Archive field
Add embeddings and hand-designed behavioral descriptors, then place valid artifacts in a
MAP-Elites-style grid. Let the user replace automatic descriptors with alien metrics during a
run.

Phase D: GLSL organism
Feed controller state into a WebGL or WebGPU simulation. Preserve deleted concepts as
sediment, encode contradictions as interference, and allow visual events to perturb semantic
state.

Phase E: Breeding chamber
Implement parent selection, ancestry requirements, ablation, offspring naming, and
descendant-fitness testing. Reject hybrids that are equivalent to running parent A and then
parent B.

Phase F: White-box lab
Add open-model hooks, activation capture, steering vectors, sparse-feature analysis, and
controlled lesions. Keep all white-box results in a distinct evidence namespace from promptlevel procedures.
The most immediately distinctive project would be the browser-based Operator Ecology
Workbench plus Semantic Cemetery visualizer. It uses the strongest existing material, fits
JavaScript/GLSL practice, produces both research data and strange visual artifacts, and gives
every future idea somewhere concrete to live.
