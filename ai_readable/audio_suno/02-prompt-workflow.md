# Prompt Workflow

## 1. Define the Systems

Fill in the following design brief before writing the final prompt:

| System | Assignment | Audible constraints |
| --- | --- | --- |
| Harmony |  |  |
| Melody |  |  |
| Rhythm |  |  |
| Timbre / atmosphere |  |  |
| Performance attitude |  |  |
| Anchor / invariant |  |  |

Name concrete techniques, instruments, tuning systems, tempos, spaces, and production behavior. Prefer “dry center-panned woodblock at 160 BPM” to “relentless percussion.”

## 2. Check the Jurisdictions

Confirm that:

- every system controls a different musical dimension;
- no ingredient has been reduced to a decorative genre label;
- the contradictions can coexist rather than cancel one another;
- the anchor is simple enough to remain recognizable;
- each assignment implies something audible.

## 3. Write Transformation Operators

For each operator, identify:

1. the systems involved;
2. the action or transformation;
3. the trigger or duration;
4. the audible result.

An operator should be testable by listening. “At bar 32, remove the midrange while the anchor continues unchanged” is operational; “become more surreal” is not.

## 4. Design the Track Arc

Map the operators onto:

`FORM → DESTABILIZE → FRACTURE → COLLAPSE → ANCHOR RETURNS → REFORM STRANGER`

Not every section needs equal length. The collapse may last only seconds, while destabilization may unfold gradually.

## 5. Build a Phonetic Engine

If the track uses vocals, treat nonsense lyrics as sound design rather than semantic text.

| Sound family | Musical function |
| --- | --- |
| Hard consonants (`k`, `t`, `p`, `g`) | Percussive attacks |
| Nasals (`m`, `n`, `ng`) | Drone and resonance |
| Open vowels (`ah`, `oh`, `oo`) | Sustained melody |
| Rolled consonants (`r`, `tr`) | Acceleration and agitation |
| Dense syllable clusters | Compressed runs |
| Long vowels | Stretched time |
| Heavy syllables | Bass weight |
| Sibilants (`s`, `sh`, `z`) | Hiss, scanlines, or noise |
| Aspirates (`h`, `f`, `wh`) | Air, wind, or decay |
| Clicks and stops (`k`, `t`, `q`) | Abrupt state changes |

Choose only the phonetic rules that support the track’s systems. Repeat them consistently enough for the vocal model to establish a behavior.

## 6. Assemble the Suno Input

Use two coordinated blocks:

### Style block

List the concrete system assignments in compact language:

- tempo and rhythmic behavior;
- tuning or harmonic practice;
- melodic technique;
- instrumentation and texture;
- vocal delivery;
- invariant.

### Lyrics / structure block

Use section tags to encode the mutation cycle and place performance or production changes at their exact transition points. Include phonetic material under the sections where it should occur.

## Final Checklist

- [ ] Ingredients have separate jurisdictions.
- [ ] The prompt describes mechanisms rather than broad moods.
- [ ] Five to ten operators drive audible changes.
- [ ] One invariant survives the transformations.
- [ ] Structural tags mark meaningful state changes.
- [ ] Vocal sounds reinforce rhythm, melody, and timbre.
