# Suno Slop

Source: `suno_slop/prompting/Suno slop.pdf`

---

Build a Suno prompt using PRODUCTIVE CONTRADICTION UNDER CONSTRAINT.
Do not begin by blending genres randomly. First invent the variables yourself.
Choose:​
[HARMONY SYSTEM]​
[MELODIC SYSTEM]​
[RHYTHMIC SYSTEM]​
[TIMBRE / ATMOSPHERE SYSTEM]​
[PERFORMANCE ATTITUDE]​
[ANCHOR / INVARIANT]
The variables should come from distinct musical traditions, techniques, eras, instruments, vocal
systems, production methods, rhythmic systems, or performance practices. Prefer combinations
that should not obviously belong together.
Assign each variable a separate jurisdiction.
Use this structure:
[HARMONY SYSTEM] controls chord behavior, voicing, consonance, dissonance, ensemble
structure, and harmonic tension.
[MELODIC SYSTEM] controls ornament, pitch movement, phrasing, contour, slides, runs,
repetition, and melodic logic.
[RHYTHMIC SYSTEM] controls pulse, subdivision, meter, syncopation, acceleration,
interruption, silence, and rhythmic density.
[TIMBRE / ATMOSPHERE SYSTEM] controls texture, instrumentation, sonic material,
production character, space, and surface quality.
[PERFORMANCE ATTITUDE] controls emotional and theatrical behavior.
[ANCHOR / INVARIANT] remains recognizable while the rest of the composition mutates.
Then invent 5–10 OPERATORS. Operators must describe transformations, not vague moods.
Use patterns such as:
hold A fixed while B migrates​
compress X into a tiny duration, then stretch Y across a huge duration​
make A behave like B without becoming B​
resolve every X into a stranger X​
alternate extreme precision with controlled collapse​
preserve X while destabilizing everything around it​

make two incompatible temporal scales coexist​
return to the anchor each time in a more mutated form
Prefer contradictions across different musical dimensions so they create tension instead of
cancelling each other.
Then write the complete Suno style prompt.
If vocals are appropriate, also create gibberish lyrics as a PHONETIC ENGINE. The nonsense
should physically reinforce the music:
hard consonants = percussion​
nasals = drone/resonance​
open vowels = sustained melody​
rolled consonants = acceleration/agitation​
dense syllables = compressed runs​
long vowels = stretched time​
heavy syllables = bass weight
Use this structural mutation cycle:
FORM → DESTABILIZE → FRACTURE → COLLAPSE → ANCHOR RETURNS → REFORM
STRANGER
Do not merely say “experimental,” “chaotic,” or “weird.”
Make the weirdness operational.
FINAL RULE:
DO NOT BLEND THE INGREDIENTS.
GIVE THEM SEPARATE JURISDICTIONS AND FORCE THEM TO NEGOTIATE.
Generate the variables yourself every time unless the user supplies one or more of them.
