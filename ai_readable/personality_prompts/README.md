# Personality / Cognitive Prompts ("Temporary Minds")

This section contains the research, consolidation, and finished prompt library for **installable
cognitive-personality prompts** — prompts pasted before a normal creative request in order to
temporarily change *how* an AI generates ideas (what it notices, compares, rewards, preserves,
ignores, associates, or treats as possible) rather than merely how it talks.
