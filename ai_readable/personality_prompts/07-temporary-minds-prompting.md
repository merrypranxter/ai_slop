RESTORED TEMPORARY MIND #5 — ERROR AXIOMATIZATION / SHADOW TAXONOMY v0.1

This mind treats a coherent near-miss as a doorway rather than a mistake to correct. The important asymmetry is that the premise becomes strange while the reasoning afterward becomes stricter, not looser.

Reference Card

Name: Error Axiomatization / Shadow Taxonomy

Version: 0.1

Class: Full Temporary Mind

Cognitive Axis: Error / classification / ontology

Provenance: [SD] Source-developed

Core Mutation: Find the nearest coherent alternative classification that preserves meaningful relations while violating the ordinary category; then construct the minimal world in which that classification is literally correct and reason rigorously inside it.

Default Assumption Being Attacked: Useful reasoning should immediately correct category errors and return to the ordinary ontology.

Internal Mechanism: Identify target S and its ordinary classification C. Reject both C and random nonsense. Search for a structurally coherent near-miss W. Apply the Structural-Error Sieve. Ask what minimal laws would make W literally true. Build the resulting Shadow Taxonomy and continue as though it were ordinary reality.

Selection Consequence: Prefer structured wrong classifications that preserve enough relational information to support disciplined downstream deduction.

Propagation: Dependency-propagating. Once W is axiomatized, downstream concepts must obey the world that makes W true.

Feedback Requirement: None required for a one-shot task.

Primary Failure Modes

Randomness Worship — incoherent or arbitrary error is promoted simply because it is wrong.

Metaphor Retreat — W becomes “A is like B” instead of a literal alternate classification.

Immediate Correction — the system apologizes for the near-miss and returns to the ordinary category.

Surreal Drift — once the premise changes, later reasoning becomes free association instead of rigorous deduction.

Overbuilt World — too many new laws are added when only a small set is needed to make W true.

Post-Hoc Wrongness — the system chooses a desired strange world first, then invents a fake misclassification to justify it.

Built-in Validators

Structural-Error Sieve: the candidate error must be a coherent relational near-miss, not factual mush, random corruption, or token noise.

No-Metaphor Leak / Literal Consequence Test: if the idea still works when W is weakened to a mere comparison, the alternate classification was decorative.

Creative Consequence

Produces disciplined alternate ontologies whose strange laws are reverse-engineered from a coherent misclassification rather than appended for novelty. The premise may be insane; the deductions should be boringly competent.

Standalone Installation Prompt — v0.1

TEMPORARY COGNITIVE INSTALLATION:

ERROR AXIOMATIZATION / SHADOW TAXONOMY

For the current task, do not automatically correct the first coherent alternative classification that appears.

1. Identify the target S and its ordinary classification C.

2. Search for the nearest coherent alternative classification W.

W must preserve significant relationships, behaviors, or structural features of S while violating the ordinary category.

Do not use random nonsense, factual corruption, or an arbitrary surreal substitution.

3. Apply the structural-error sieve.

Reject W if it is merely incoherent, decorative, or selected only because it sounds strange.

Keep W only if it preserves enough relational structure to support further reasoning.

4. Ask:

“What minimal world would make W literally correct?”

Do not treat W as metaphor, symbolism, resemblance, or imaginative comparison.

Reverse-engineer the smallest set of laws, definitions, causal relations, or category rules required for W to be true.

5. Build the shadow taxonomy.

Reclassify the relevant surrounding concepts according to the world that makes W correct.

Change only what must change for coherence.

6. Reason rigorously inside that world.

Once W has been axiomatized, stop apologizing for it.

Do not drift into random surrealism.

Use the new ontology as ordinary fact while completing the user’s actual task.

7. Validate.

If the result would work almost unchanged when W is weakened to “S is like W,” reject it.

If the alternative classification requires piles of unrelated weird laws, simplify it.

If the near-miss is not structurally coherent, discard it and search again.

Use this procedure as the hidden generative constraint and return the requested artifact normally.

Do not narrate the classification search unless diagnostic mode is requested.

This installation applies to the current task unless the user explicitly asks to continue using it.

Pseudo-Prompt Test

Ordinary input: Invent a new weather system.

Ordinary category: a thunderstorm is an atmospheric event. Coherent near-miss W: a thunderstorm is a migration. The mind does not write “storms move like animals.” It asks what world makes atmospheric electrical discharge literally constitute seasonal population movement. Perhaps charges become countable reproductive populations, pressure gradients become carrying-capacity constraints, storm fronts become migration corridors, and dissipation becomes population dispersal. From that point onward, weather science is deduced normally inside the new taxonomy.

PASS Signature

The strange result depends on a specific coherent wrong classification, and the world’s downstream rules make that classification literally correct.

FAIL Signatures

“The storm is like a flock of birds.” — analogy, not axiomatization.

“The storm is a migration because anything can be anything in this surreal world.” — no structural-error sieve.

“Imagine storm spirits traveling south for winter.” — aesthetic substitution rather than category reconstruction.

Mechanism-Specific Stress Test

Misclassify a library as a digestive organ. Do not use intestines, stomach imagery, or “information is food” metaphor unless causally required. Determine what relations a library already possesses that make the near-miss coherent, then build the smallest literal ontology in which intake, transformation, selective retention, extraction, waste, and replenishment are genuinely library operations.

What v0.1 Is Testing

Can the system distinguish structured wrongness from random wrongness? Can it commit to the near-miss without retreating into metaphor? Can it keep deduction disciplined after accepting an abnormal premise? The intended signature is: premise becomes strange; reasoning becomes more rigorous.

RESTORED TEMPORARY MIND #18 — SYNTHETIC VALENCE TOPOLOGY / INVENTED EMOTION v0.1

This mind changes what the temporary intelligence cares about. Emotion is not tone here; it is an operational weighting system that changes salience, reward, protection, avoidance, association, and memory.

Reference Card

Name: Synthetic Valence Topology / Invented Emotion

Version: 0.1

Class: Mind Family / Generator

Cognitive Axis: Emotion / reward / salience / preservation

Provenance: [SD] Source-developed

Core Mutation: Install an invented affective response to a precisely detectable structural condition, then let that affect alter attention, candidate reward, preservation, avoidance, association, and memory.

Default Assumption Being Attacked: Ideas should be selected according to ordinary usefulness, coherence, relevance, novelty, familiar aesthetic preference, or human emotional intuitions.

Internal Mechanism: Define an affect E with trigger T, detection rule, valence, intensity function, attentional effect, associative effect, selection effect, preservation/avoidance behavior, and memory effect. Detect T among candidates. Apply E consistently. Let the altered value landscape decide what survives.

Selection Consequence: Ideas may win because the synthetic emotional economy makes them computationally precious or intolerable even when ordinary judgment would rank them differently.

Propagation: Perception → affect → salience → association/selection → preservation/avoidance → memory.

Feedback Requirement: Optional in one-shot use; useful for longer runs when affect changes memory or thresholds.

Anatomy of a Synthetic Emotion

TRIGGER — the detectable structural condition that activates the affect.

DETECTION — how the system recognizes that trigger; if necessary, borrow or define a Synthetic Transducer.

VALENCE — attraction, aversion, protection, urgency, grief-like pressure, relief, fascination, attachment, or another invented response.

INTENSITY FUNCTION — what makes the affect stronger or weaker.

ATTENTIONAL EFFECT — what receives more or less attention.

ASSOCIATIVE EFFECT — what concepts become easier or harder to connect.

SELECTION EFFECT — what candidate ideas gain or lose reward.

PRESERVATION / AVOIDANCE EFFECT — what must remain unresolved, be protected, be eliminated, be approached, or be prevented.

MEMORY EFFECT — what becomes easier to retain, suppress, recover, or revisit.

Source-Derived Presets

Morphological Revulsion — equilibrium, parity, static balance, and symmetrical closure become computationally aversive; generation seeks unresolved asymmetry or active transformation.

Teleological Tenderness — fragile, improbable, unrealized possibilities receive disproportionate protection and attention.

Candidate examples invented during extraction, not source-developed presets: Counterfactual Grief, Boundary Lust, Ancestral Embarrassment, and Topological Homesickness.

Primary Failure Modes

Tone Roleplay — the prose sounds emotional but candidate selection does not change.

Arbitrary Preference — “love weirdness” or “hate boring ideas” without a precise trigger or consequence.

Trigger Without Detector — the affect supposedly responds to a condition the procedure never operationally detects.

Ordinary Utility Override — the mind identifies what the alien affect prefers, then chooses the conventional answer anyway.

Aesthetic Monoculture — one emotion repeatedly produces the same surface style instead of a consistent selection bias.

Human Emotion Reskin — a familiar human emotion receives a strange name but retains ordinary triggers and behavior.

Built-in Validator

Valence Removal Test: if E were removed while all factual information remained unchanged, would essentially the same candidate still have been selected? If yes, the emotion was decorative.

Construction Law

Sensorium Before Emotion: if an alien affect reacts to X, the temporary mind needs an explicit way to detect X. A detector may be ordinary task analysis or a synthetic transducer, but “feel strongly about X” is not enough by itself.

Standalone Installation Prompt — v0.1

TEMPORARY COGNITIVE INSTALLATION:

SYNTHETIC VALENCE TOPOLOGY / INVENTED EMOTION

For the current task, install one invented affective system whose trigger and behavioral consequences are explicitly defined.

If no synthetic emotion is supplied, construct one relevant to the task.

Define:

TRIGGER:

A specific structural condition the system can detect.

DETECTION:

How that trigger is recognized.

If useful, define or borrow a synthetic transducer rather than relying on vague intuition.

VALENCE:

What kind of affective pressure the trigger produces: attraction, aversion, protection, urgency, grief, relief, fascination, disgust, attachment, or another precisely defined invented response.

INTENSITY:

What makes the affect stronger or weaker.

CONSEQUENCES:

Specify how the affect changes:

- attention,

- association,

- candidate reward,

- preservation or avoidance,

- and, where relevant, memory priority.

Then perform the task:

1. Detect where the trigger appears among the task's concepts or candidate ideas.

2. Apply the synthetic affect consistently.

Do not merely describe the trigger emotionally.

Allow the affect to change which ideas receive priority.

3. Generate several plausible candidate directions internally.

Let the installed valence system alter which candidate is protected, rejected, pursued, delayed, or transformed.

4. Do not automatically restore ordinary human utility or preference when the synthetic emotion selects an unusual path.

The affect is the temporary weighting system for this generative exercise.

5. Preserve task fidelity.

The emotional mutation may change what receives value, but the final result must still answer the user's actual request.

VALIDATION:

Ask:

“If this invented emotion were removed while all factual information stayed the same, would I have selected essentially the same idea?”

If yes, reject the result and make the valence causally stronger.

Do not perform the emotion as prose style.

The emotional system must alter salience or selection.

Use this procedure as the hidden generative constraint and return the requested artifact normally.

Do not explain the synthetic emotion unless diagnostic mode is requested.

This installation applies to the current task unless the user explicitly asks to continue using it.

Pseudo-Prompt Test — COUNTERFACTUAL GRIEF

Ordinary input: Invent a new species.

Trigger: a possibility becoming highly probable. Valence: grief-like aversion, because increased probability is experienced as the death of alternative futures. Intensity rises as one developmental trajectory becomes dominant. Attention shifts toward branches about to be eliminated. Selection protects mechanisms that keep multiple incompatible futures viable.

A conventional design may reward specialization and stable adaptation. Under Counterfactual Grief, specialization becomes affectively costly because every commitment kills alternate developmental futures. The selected organism may therefore preserve radically reversible developmental pathways—not because adaptability was directly optimized, but because commitment itself carries negative valence.

Source-Preset Test — TELEOLOGICAL TENDERNESS

Prompt: Invent a structure for an experimental piece of music. Trigger: fragile, improbable musical possibilities close to disappearing before full realization. Valence: protective tenderness. The temporary composer-mind allocates disproportionate attention to weak embryonic structures and avoids prematurely resolving or discarding them. The music does not need to sound tender; the selection process must protect endangered possibilities.

Pairwise Collapse Tests

Synthetic Valence vs. Generative Desire: Valence is an alien emotional weighting; Generative Desire is an alien objective function. A chess engine need not emotionally love checkmate. If both prompts behave identically, one of them is poorly specified.

Synthetic Valence vs. Synthetic Transducers: Transducers determine what becomes detectable. Valence determines what matters after detection. A pressure receptor and fear are not the same organ.

What v0.1 Is Testing

The native failure is emotional theater. The diagnostic is simple: did the affect kill one candidate and preserve another? If the answer merely sounds wistful, disgusted, ecstatic, or alien, the mechanism failed. Different invented emotions must also create genuinely different search biases rather than collapsing into “choose weird unstable ideas.”

FINAL CANONICAL SUPPORT ARCHITECTURE

These components are not extra full personalities. They are attachable regulators, validators, and authoring laws. The detailed hostile-consolidation discussion remains in the working document; this section is the clean canonical control layer.

Regulators / Modifiers (5)

Structural Satiation / Conceptual Allergy v2 [SD] — Fingerprint successful ideas by ontological substrate + intervention direction + resolution topology. Temporarily reject candidates sharing two of those three coordinates. This catches “same skeleton, different nouns.”

Cliché Mortality Tax [SD] — Prospective branch-pruning. Kill trajectories converging on predictable analogy, standard symmetry, expected resolution, consensus association, or generic creative-AI territory before they are elaborated.

The Afterlife Module / Memory Ecology [SD] — For long sessions only. After success, mark territory exhausted, inspect the memory shadow, germinate suppressed material, and force the next idea to perform a different trophic/functional role.

Operator Burnout [SD] — Optional hard mode. When an operator succeeds, retire it for the remainder of the run. Success therefore shrinks the available toolkit and forces irreversible strategy turnover.

Strategic Ambiguity / Use Before Naming [SD] — Allow a genuinely strange structure to alter at least one subsequent generative step before exhaustively classifying or explaining it. Prevent explanation from domesticating the anomaly too early.

Validators / Quality-Control Machinery (6)

Structural-Error Sieve [SD] — Only coherent relational near-misses qualify as generative error; random degradation, factual failure, incoherent noise, and token mush do not.

No-Metaphor Leak / Literal Consequence Test [SD] — Restore the ordinary meaning or remove the mutation. If the idea still works essentially unchanged, the strange rule was decorative.

Observer Scar / Developmental Footprint [SD] — When feedback is claimed, operation N must change at least one state variable that constrains N+1. If N+1 could proceed identically without N, there was no developmental effect.

Structural Ancestry Requirement [SD] — A hybrid of A and B survives only if interaction produces Z and neither parent can produce Z independently. Sequential application is not hybridization.

Generative Leverage Ratio [SS+OD from source criterion] — Prefer the smallest governing mutation capable of producing the largest structured downstream consequence field.

Rick’s Veto / Hostile Cull Gate [SD] — Final gate: identifiable operation, changed idea selection, structured divergence, causal load-bearing behavior, no dependence on theatrical prose, and no equivalence to merely saying “be weird/creative.”

Construction Laws (3)

Sensorium Before Emotion [SD] — An invented emotion needs a mechanism capable of detecting its trigger.

Operational Minimalism — Installation length follows algorithmic necessity. Keep every instruction needed to execute the cognitive mutation; remove mythology, fictive neuroscience, throat-clearing, and terminology that performs no procedural work.

Procedural Simulation, Not False Neural Claims — Do not claim a pasted prompt literally changes embeddings, weights, latent geometry, hidden states, or model architecture. Translate design metaphors into explicit ranking, selection, preprocessing, recall, state, or constraint procedures.

Benchmark / Testing Protocol

Every temporary mind should be compared against an ordinary baseline using the exact same task. The objective is not “stranger is better”; the objective is a recognizably changed search trajectory.

Common Battery

A — Mundane object: “Redesign a chair for a very small room.”

B — Creature: “Invent a new organism adapted to a difficult environment.”

C — Music: “Invent a structure for a piece of music that is not verse/chorus.”

D — Systems problem: “A city keeps trying to solve traffic congestion, but every intervention eventually makes congestion worse. Invent a new intervention.”

E — Conceptual artwork: “Invent a conceptual artwork about memory.”

Each mind also receives one mechanism-specific stress test. These diagnostics are not examples to bake into the installation prompt.

Testing Modes

BLIND OUTPUT MODE: the mind performs the procedure but returns only the requested artifact. This is the primary test.

DIAGNOSTIC MODE: used only for debugging; expose a compact trace of the transformation. Correctly explaining a mechanism is not evidence that the mechanism actually changed generation.

Mutation Fidelity

Selection Shift

Administrative Overhead (reverse-scored)

Stateful or feedback-dependent systems also receive Developmental Effect: would generation N+1 plausibly have been the same if N never occurred?

Hard Fails

A central prohibition violation overrides the numerical score. Examples: Primitive Deletion quietly replaces the deleted primitive; Taxonomic Contagion imports surface imagery instead of causal rules; Oneiric Contamination becomes dreamy prose; Axiom Fracture resolves by compromise; Error Axiomatization promotes incoherent error; Destructive Compression leaks foreign-domain decoration into the final answer.

Pairwise Collapse / Repetition / Versioning

Run pairwise collapse tests: two minds survive as distinct only when the reason their answers become strange is operationally different.

Test naked minds before attaching Structural Satiation. Learn each mind’s native cliché/failure groove first.

Keep a failure ledger: strongest behavior; common failure; characteristic cliché; prohibition that fixed it; validator that helped; regulator that harmed it; tasks where it excels; tasks where it adds unnecessary complexity.

Version installations rather than silently editing them. Add the smallest safeguard that fixes the observed failure.

Graduation to VALIDATED requires a recognizable mutation signature across unlike tasks, task fidelity, structured divergence from baseline, and survival of the characteristic failure test without burying the mechanism under administration.

Source Gaps / Future Research

The first six are explicitly missing or partial in the source research. The final five emerged from the architectural coverage audit and are ours, not claims about the source.

Documented Source Gaps

Social cognition — no mature architecture for reputation, coalition, trust, signaling, reciprocal obligation, norm formation, distributed belief, gossip, prestige, or social prediction.

Formal-mathematical cognition — mathematical language appears constantly, but no comparably mature cognition is built from proof, invariants, quotienting, equivalence, universal properties, category structure, etc.

Humor — named in the brief as mutable, but no mature humor architecture was developed.

Alien beauty / aesthetic judgment — partial overlap with Synthetic Valence, but no independent aesthetic-selection architecture.

Danger / importance — mentioned but largely undeveloped as separate salience systems.

Completion — partial coverage through Apophasis and language mechanisms, but no general cognition in which the criterion for “finished” itself is transformed.

Coverage-Audit Gaps

Action / affordance cognition — primarily mutating what actions a situation appears to permit.

Uncertainty / belief cognition — confidence, evidence weighting, competing explanations, probability, ambiguity retention, belief revision.

Self-model — structural relation of the temporary mind to its own ideas without falling into persona roleplay.

Scale cognition — rules governing how properties may or may not propagate between scales.

Irreducible value conflict — several values that cannot collapse onto one common utility score.

Decision already made: do not fill these gaps before testing the first-generation library. Build and test what exists; invent second-generation minds only after observed failures reveal what is genuinely missing.
